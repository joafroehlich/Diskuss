f(x) = 2 * sin x + 1          x im Bogenmaß

f'(x) = 2 * cos x

f''(x) = -2 * sin x

f'''(x) = -2 * cos x

Definitionsbereich:    0 ≤ x ≤ 2π 

Wertebereich: -1 ≤ f(x) ≤ 3 (siehe Extrempunkte)

Symmetrie zur y-Achse bzw. zum Punkt (0|0):

keine Achsensymmetrie bei Sinusfunktionen

-f(-x) = -(2 * sin (-x) + 1) 

-f(-x) = -2 * -sin x – 1 

-f(-x) = 2 * sin x – 1 ≠ f(x) 

--> keine Punktsymmetrie

Nullstellen: 

f(x) = 0

2 * sin x + 1 = 0 |-1

2 * sin x = -1 |:2

sin x = -0,5

x1 = (7/6)π = 3,67 ≙ 210°

x2 = (11/6)π = 5,76 ≙ 330° 

N1(3,67|0), N2(5,76|0)

Schnittpunkt mit der y-Achse: 

x = 0

2 * sin 0 + 1 = 1

Sy(0|1)

Extrempunkte:

f'(x) = 0

2 * cos x = 0 |:2

cos x = 0

x1 = π/2 = 1,57 ≙ 90° 

f(1,57) = 2 * sin 1,57 + 1 = 3

x2 = (3/2)π = 4,71 ≙ 270° 

f(4,71) = 2 * sin 4,71 + 1 = -1
 
f''(1,57) = -2 * sin 1,57 = -2 < 0 

--> Hochpunkt (1,57|3)

f''(4,71) = -2 * sin 4,71 = 2 > 0 

--> Tiefpunkt (4,71|-1)

Wendepunkte:

f''(x) = 0

-2 * sin x = 0 |:(-2)

sin x = 0

x1 = 0 ≙ 0°, f(0) = 2 * sin 0 + 1 = 1  

f'''(0) = -2 * cos 0 ≠ 0 --> WP1(0|1)

x2 = π = 3,14 ≙ 180° 

f(3,14) = 2 * sin 3,14 + 1 = 1

f'''(3,14) = -2 * cos 3,14 ≠ 0 --> WP2(3,14|1)

x3 = 2 * π = 6,28 ≙ 360° 

f(6,28) = 2 * sin 6,28 + 1 = 1

f'''(6,28) = -2 * cos 6,28 ≠ 0 --> WP3(6,28|1)
