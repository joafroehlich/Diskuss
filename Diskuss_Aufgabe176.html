f(x) = x * sin x           x im Bogenmaß

Produktregel erste Ableitung:

u = x, u' = 1

v = sin x, v' = cos x

f'(x) = 1 * sin x + cos x * x 

f'(x) = sin x + x * cos x

Summen- und Produktregel zweite Ableitung:

u = x, u' = 1

v = cos x, v' = -sin x

f''(x) = cos x + 1 * cos x + (-sin x) * x 

f''(x) = 2 * cos x - x * sin x 

Summen- und Produktregel dritte Ableitung:

u = -x, u' = -1

v = sin x, v' = cos x

f'''(x) = -2 * sin x + (-1) * sin x + cos x*(-x)

f'''(x) = -3 * sin x - x * cos x

Definitionsbereich:    0 ≤ x ≤ 2π

Wertebereich:  -4,81 ≤ f(x) ≤ 1,82  
(siehe Extrempunkte)

Symmetrie zur y-Achse bzw. zum Punkt (0|0):

f(-x) = (-x) * sin (-x) = (-x) * -sin x 

f(-x) = x * sin x = f(x)  

--> Achsensymmetrie

-f(-x) = -x * sin x ≠ f(x)

--> keine Punktsymmetrie 

Nullstellen:

f(x) = 0
