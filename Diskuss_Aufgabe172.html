Aufgabe 172

f(x) = 1 - 2 * cos x          x im Bogenmaß

f'(x) = 2 * sin x

f''(x) = 2 * cos x

f'''(x) = -2 * sin x

Definitionsbereich:    0 ≤ x ≤ 2π 

Wertebereich: -1 ≤ f(x) ≤ 3 (siehe Extrempunkte)

Symmetrie zur y-Achse bzw. zum Punkt (0|0):

f(-x) = 1 - 2 * cos  = 1 – 2 * cos x = f(x)  

--> Achsensymmetrie

-f(-x) = -(1 - 2*cos (-x)) = -1 + 2*cos x ≠ f(x) 

--> keine Punktsymmetrie 

Nullstellen:

f(x) = 0

1 - 2 * cos x = 0 |+2 * cos x

2 * cos x = 1 |:2

cos x = 0,5

x1 = (1/3)π = 1,05 ≙ 60°

x2 = (5/3)π = 5,24 ≙ 300° 

N1(1,05|0), N2(5,24|0)

Schnittpunkt mit der y-Achse: 

x = 0 

1 - 2 * cos 0 = -1

Sy(0|-1)

Extrempunkte:

f'(x) = 0

2 * sin x = 0 |:2

sin x = 0

x1 = 0 ≙ 0°, f(0) = 1 - 2 * cos 0 = -1

x2 = π = 3,14 ≙ 180° 

f(3,14) = 1 - 2 * cos 3,14 = 3

x3 = 2π = 6,28 ≙ 360° 

f(6,28) = 1 - 2 * cos 6,28 = -1
 
f''(0) = 2 * cos 0 = 2 > 0 

--> Tiefpunkt (0|-1)

f''(3,14) = 2 * cos 3,14 = -2 < 0 

--> Hochpunkt (3,14|3)

f''(6,28) = 2 * cos 6,28 = 2 > 0 

--> Tiefpunkt (6,28|-1)

Wendepunkte:

f''(x) = 0

2 * cos x = 0 |:(-2)

cos x = 0

x1 = π/2 = 1,57 ≙ 90° 

f(1,57) = 1 - 2 * cos 1,57 = 1  

f'''(1,57) = -2 * sin 1,57 ≠ 0 --> WP1(1,57|1)
 
x2 = (3/2) * π = 4,71 ≙ 270° 

f(4,71) = 1 - cos 4,71 = 1  

f'''(4,71) = -2 * sin 4,71 ≠ 0 --> WP2(4,71|1)
