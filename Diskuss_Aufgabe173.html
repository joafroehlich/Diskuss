f(x) = x * cos x            x im Bogenmaß

Produktregel erste Ableitung:

u = x, u' = 1

v = cos x, v' = -sin x

f'(x) = 1 * cos x + (-sin x) + x  

f'(x) = cos x - x * sin x

Summen- und Produktregel zweite Ableitung:

u = -x, u' = -1

v = sin x, v' = cos x
 
f''(x) = -sin x + (-1 * sin x + cos x * (-x)) 

f''(x) = -sin x - sin x - x * cos x 

f''(x) = -2 * sin x - x * cos x

Summen- und Produktregel dritte Ableitung:

u = -x, u' = -1

v = cos x, v' = -sin x

f'''(x) = -2 * cos x - 1 * cos x - sin x * (-x)

f'''(x) = x * sin x - 3 * cos x

Definitionsbereich:    0 ≤ x ≤ 2π  

Mit 2π = 6,28

Wertebereich: -3,29 ≤ f(x) ≤ f((6,28)) = 6,28  

(für -3,29 siehe Extrempunkt)

Symmetrie zur y-Achse bzw. zum Punkt (0|0):

f(-x) = -x * cos (-x) = –x * cos x ≠ f(x)  

--> keine Achsensymmetrie

-f(-x) = -(-x * cos x) = x * cos x = f(x)

--> Punktsymmetrie
